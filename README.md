# Tender_Bot — мини-приложение аукциона б/у гофротары

Мини-приложение для мессенджера **MAX**: закрытые B2B-аукционы на повышение цены на свежие
б/у банановые коробки. Организатор публикует тендер из приложения, бот отправляет карточку
в групповой чат, участники торгуются, победитель подтверждает выкуп.

> Стек: React 18 + TypeScript + Vite + MAX Bridge. Бэкенд аукциона — отдельный проект
> (`C:\Users\1\auction-max`, FastAPI + PostgreSQL, вся бизнес-логика в PL/pgSQL).

## Структура репозитория

```

  src/main.tsx       роутинг по start_param + сессия из initData
  src/api.ts         клиент API, разбор ошибок, демо-фолбэк

  src/ui.tsx         элементы интерфейса (таймер, галерея, топ-3, лента)
  src/demo.ts        демо-данные (только когда API недоступен)
  public/config.js   конфигурация окружения — правится на хостинге без пересборки
  public/spike.html  диагностическая страница Bridge (initData, start_param)
docs/                СБОРКА = корень GitHub Pages (источник Pages: master:/docs)
  index.html         собранное приложение
  assets/            JS/CSS бандлы
  config.js          копия app/public/config.js
  demo/              фотографии для карточек и демо-режима
  spike.html         диагностика Bridge
```

## Сборка и публикация

```bash
cd app
npm install --no-fund --no-audit     # из РФ — через прокси: HTTPS_PROXY=http://127.0.0.1:10808
npm run build                        # tsc --noEmit && vite build → ../docs
cd .. && git add -A && git commit -m "…" && git push
```

Проверка типов и сборка выполняются одной командой; выход сборки — `docs/`, откуда её
раздаёт GitHub Pages, поэтому URL фото (`docs/demo/…`) не меняются между сборками.

## Настройка адреса API

`docs/config.js` (и исходник `app/public/config.js`):

```js
window.AUCTION_CONFIG = {
  apiBase: "https://api.ваш-домен.ru",  // публичный HTTPS-адрес бэкенда аукциона
  demoFallback: true,                   // показывать демо, если API недоступен
};
```

* Файл подключается до бандла, поэтому адрес API меняется **без пересборки** — правкой на хостинге.
* Сейчас в `config.js` указан рабочий адрес: `https://6dd076a81dde9d.lhr.life` (временный
  HTTPS-туннель с компьютера разработчика для обкатки с телефона). После деплоя API на сервер
  поменяйте значение на постоянный адрес — пересборка приложения не нужна.

## Проверка без телефона

```bash
cd app
node scripts/smoke.mjs                                        # список/карточка на демо-данных
USE_DOCS_CONFIG=1 INITDATA_FILE=<файл с initData> node scripts/smoke.mjs tender
```

Второй запуск берёт реальный `docs/config.js` и подписанный initData (его готовит
`scripts/make_test_initdata.py` в проекте API) — приложение обращается к опубликованному API
и рендерит настоящий тендер. Так проверяется вся цепочка, кроме самого MAX.
* Если API недоступен (или открыли `?startapp=demo`), приложение показывает интерфейс на
  демо-данных и **обязательно** выводит плашку «ДЕМО-РЕЖИМ».
* `spike.html` остаётся для диагностики Bridge: показывает `initData`, `start_param`, доступные методы.

## Как открывается приложение

Кнопка `open_app` в карточке тендера, которую бот отправляет в чат:

```json
{ "type": "open_app", "text": "Участвовать",
  "web_app": "id3435300855_4_bot", "payload": "tender_BK-2026-000001" }
```

`web_app` — имя бота, `payload` доезжает до приложения как `start_param`
(проверено на спайке: параметр передаётся только через `payload`). Приложение разбирает:

| start_param | Экран |
|---|---|
| `tender_<код>` | карточка тендера (цена, таймер, топ-3, лента, ставки) |
| `create` | форма создания тендера (только для организатора) |
| `demo` | карточка тендера на демо-данных |
| пусто | список тендеров |

## Что реализовано в интерфейсе
* Карточка: галерея со свайпом, параметры партии, крупная текущая цена, таймер с серверной
  коррекцией (последняя минута — акцентный цвет), топ-3 с подсветкой лидера, лента ставок.
* Ставки: зелёная кнопка «Сделать ставку: {сумма} ₽» + «Своя цена»; у лидера кнопка неактивна
  («Вы лидируете»); подтверждение вторым касанием; предупреждение при цене на >50 % выше текущей.
* Ошибки ставки по кодам сервера: 409 — «Цена изменилась, новая минимальная ставка: X»,
  429 — «Слишком часто, подождите N сек» с обратным отсчётом, оффлайн — «Ставка не отправлена.
  Повторить». Каждая попытка несёт свой `idempotency_key` (повтор не создаёт дубль).
* Итоги: победитель и контакты (только организатору и победителю), «Подтверждаю выкуп»,
  завершение без ставок с «Перезапустить», отмена для организатора.
* Создание тендера: город, сеть, количество 8 400–25 200, 24/48 ч, цена с двумя знаками,
  до 5 фото со сжатием на телефоне (≤ 2000 px) и загрузкой через presigned URL.
* Тёмная тема, кнопки не ниже 48 px, skeleton-загрузка, haptic-отклик, кнопка «Назад» мессенджера.
