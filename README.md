# tender-bot-miniapp

Мини-приложение (placeholder для спайка) бота **Tender_Bot** — аукцион б/у гофротары,
проект `auction-max`.

**Назначение:** дать рабочий HTTPS-URL, который можно привязать к боту в MAX и проверить
кнопку `open_app` из карточки тендера, launch-параметры (`start_param`), подпись
`initData` и вызовы MAX Bridge.

Статика, без сборки: `index.html` открывается как есть. Содержит:
- вывод `initDataUnsafe` (user/chat/start_param), платформы и версии Bridge;
- флаг наличия `hash` в `initData` (строка для проверки подписи на бэкенде) и кнопку её копирования;
- проверку доступности `HapticFeedback`, `BackButton`, `SecureStorage`;
- корректный fallback вне MAX (мок, без ошибок в консоли).

## Как привязать к боту

Панель управления ботом → **Расширенные настройки → Настроить** → вставить URL мини-приложения
(`https://kasper444.github.io/tender-bot-miniapp/`) → выбрать кнопку → **Сохранить**.

Требования MAX к URL: только `https://`, ≤1024 символов, латиница/цифры/точка/дефис, без пробелов.

## Проверка

1. Открыть URL в браузере — страница должна отрисоваться, статус «браузер (мок)».
2. Запустить из MAX: карточка тендера → кнопка **«Участвовать»** (`open_app`) →
   приложение должно открыться внутри MAX, статус «внутри MAX», а в поле `start_param`
   появиться код тендера из диплинка (`tender_BK-2026-000001`).
